### Technology Stack

### Purpose

The Technology Stack defines the software technologies, frameworks, development tools, hosting services, and cloud services used in the development and deployment of SMARTCLASS. The selected stack prioritizes modern web development practices, scalability, maintainability, cost-effectiveness, and compatibility with AI-assisted development using Replit AI.

SMARTCLASS follows a full-stack web application architecture consisting of:

* Frontend Layer

* Backend Layer

* Database Layer

* File Storage Layer

* Authentication Layer

* Deployment Layer

* Development Environment

### Frontend Layer

The Frontend Layer is responsible for rendering the user interface and handling all user interactions for students, teachers, administrators, and the public kiosk dashboard.

| Technology      | Purpose                                                |
| --------------- | ------------------------------------------------------ |
| React 19        | Component-based user interface development             |
| TypeScript      | Type safety and better maintainability                 |
| Vite            | Fast development server and optimized production build |
| Tailwind CSS    | Utility-first responsive styling                       |
| React Router    | Client-side routing and navigation                     |
| TanStack Query  | Server-state fetching and caching                      |
| React Hook Form | Form handling and validation                           |
| Zod             | Schema-based input validation                          |

### Frontend Responsibilities

* Public Dashboard (Idle Screen)

* Student Portal

* Teacher Portal

* Administrator Portal

* Attendance Interface

* Announcement Display

* Presentation Interface

* Academic Performance Display

* Responsive and touchscreen-friendly UI

### Backend Layer

The Backend Layer handles business logic, API processing, authentication, authorization, database operations, and file management.

| Technology | Purpose                        |
| ---------- | ------------------------------ |
| Node.js    | JavaScript runtime environment |
| Express.js | REST API framework             |
| TypeScript | Type-safe backend development  |
| Prisma ORM | Database modeling and querying |
| Multer     | File upload handling           |
| Zod        | Request validation             |

### Backend Responsibilities

* Authentication

* Role-Based Access Control (RBAC)

* Attendance Processing

* Grade Management

* Announcement Management

* Presentation Material Management

* Report Generation

* File Upload Validation

* API Security

* Database Transactions

### Database Layer

The Database Layer stores all structured data used by SMARTCLASS.

Primary Database

PostgreSQL (Supabase)

Relational database for students, teachers, attendance, grades, schedules, announcements, and system settings.

### Why PostgreSQL?

* Strong relational support

* Excellent data integrity

* Scalable architecture

* Works seamlessly with Prisma

* Suitable for complex attendance and reporting queries

* Easy migration to larger deployments

### Supabase Free Tier (Prototype)

* 500 MB PostgreSQL storage

* Daily backups

* SQL editor

* Dashboard management

* REST and direct database access

### File Storage Layer

Uploaded files are stored separately from the database.

File Storage

Cloudflare R2

Stores PDFs, PowerPoint files, images, profile pictures, schedule images, and other uploaded media.

### Stored Files

* Presentation PDFs

* PowerPoint files

* Announcement images

* Student profile pictures

* Class schedule images

### Upload Policy

| File Type  | Maximum Size |
| ---------- | ------------ |
| PDF        | 10 MB        |
| PPT / PPTX | 10 MB        |
| PNG / JPG  | 5 MB         |

Large videos are not stored in the system and should be presented using the Mini PC directly or through HDMI connection.

### Classroom Kiosk Deployment

The Mini PC does not host the backend or database.

Instead, it acts as a dedicated kiosk device that opens the online SMARTCLASS system in full-screen mode.

### Kiosk Flow

Windows 11 Pro

Google Chrome / Microsoft Edge

[https://smartclass.school-domain.com](https://smartclass.school-domain.com)

Full-Screen Kiosk Mode

This ensures that all classrooms access the same centralized database and files in real time.
